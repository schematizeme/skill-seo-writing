**schematize-seo-writing** — redação SEO hierárquica: estrutura, briefings, conexão, texto.

| Comando | O que faz |
|---|---|
| `/seow-help` | esta lista |
| `/seow-write` | modo completo: os 4 passos, checador, 5 blocos de entrega |
| `/seow-outline` | só estrutura + briefings + checklist de conexão, para aprovar antes de escrever |
| `/seow-revise` | modo revisão: texto pronto, extrai estrutura, deriva briefings, reescreve nas regras |
| `/seow-check` | roda `scripts/checar-texto.mjs` num artigo (e briefings) e lista os achados |
| `/seow-load` | carrega à força TODO o corpo normativo e passa a aplicá-lo |
| `/seow-claude` | cria ou mescla o `CLAUDE.md` sempre-on de redação SEO na raiz do repo |
| `/seow-cc` · `/seow-handoff` | context compact / handoff no archive |

Pareia com: `schematize-seo` (estratégia, técnico, `/seo-keywords`, dados estruturados, AIO),
`schematize-web` (publicar a página), `schematize-institutional` (inventário de páginas).
